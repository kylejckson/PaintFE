# Quick start

Open an image, make your edits, then save your work. This introduction is available offline.

## Open or create an image

Use File > New for a blank canvas or File > Open for an existing image. Documents open in separate tabs so you can work on several images.

## Find your way around

Choose a tool, then adjust its options above the image. Pick colours in the Color panel. Zoom in to inspect detail and pan to move the view. Hold Space to pan temporarily.

## Build your edit

Paint on the active layer. Add layers to keep parts of your image separate, and use selections to limit an edit. Text and Shapes add lettering and geometric elements.

## Move and transform

Position pasted content before applying it. For tool previews, Apply or Enter commits the edit; Cancel or Escape discards it. Canvas > Rotate Canvas contains Straighten Canvas. Mesh Warp and Liquify reshape pixels.

## Undo and redo

Use Edit > Undo or Redo to step through edits. Undo discards an unapplied tool preview and undoes one committed edit. Preferences > Editing can include individual tool adjustments. Text fields keep their own Undo.

## Save your work

Use File > Save to save your document. Choose PFE in Save As to keep editable layers, or PNG and JPEG for sharing. Keep a PFE copy when you expect to edit the layers again.
